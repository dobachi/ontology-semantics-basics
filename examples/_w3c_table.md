: W3C の主要標準 {#tbl-w3c}

**考察**

これらは役割で分けると理解しやすいと考えられる。
RDF は「書き方」、RDF Schema と OWL は「語彙と論理」、SKOS は「用語の階層」、SHACL は「検査」、SPARQL は「問い合わせ」、JSON-LD は「開発者になじむ直列化」、DCAT は「データの目録」である。
